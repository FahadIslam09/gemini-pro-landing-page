# Google AI Pro — Premium Landing Page & Storefront

A pixel-perfect, high-conversion Bengali landing page and storefront for Google AI Pro subscription tiers, inspired by [Google AI Subscriptions](https://gemini.google/subscriptions/) and [Google One AI Plans](https://one.google.com/about/google-ai-plans/).

## 🚀 Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router, React 19)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: Framer Motion & Canvas Confetti
- **Typography**: `Hind Siliguri` (Bengali) + `Outfit` (Headings & Badges)

## ✨ Key Features

- **Hero with Live Interactive Gemini Sandbox**: Live simulated query execution for Deep Research, Veo 3.1 4K video, Lyria 3 music, and AI coding.
- **Why Google AI Pro**: 5-card responsive feature grid detailing Gemini 3.1 Pro (1M context), Deep Research, Creative Studio, Autonomous Coding (Antigravity & Jules), and 5 TB Cloud Storage.
- **Interactive Feature Deep Dive**: 5-tab showcase with active multi-agent and storage pool previews.
- **13-Row Feature Comparison Matrix**: Detailed side-by-side comparison between Free Gemini and Google AI Pro.
- **Duration Pricing Switcher**: 1 Month, 12 Months, and 18 Months Best Value (@ ৳499 BDT) with savings calculator.
- **Local Payment Checkout Modal**: bKash, Nagad, and Rocket support with clipboard copy, toast notifications, multi-stage loading progress states, and celebratory confetti receipt.
- **Mobile Optimized**: Sticky bottom checkout bar, responsive slide-out navigation drawer.

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
